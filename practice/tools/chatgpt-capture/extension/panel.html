ChatGPT Capture

Record one small chatgpt.com flow, then export a sanitized evidence bundle.

Open chatgpt.com in the inspected tab.

What is exported?
  • Allowlisted HAR metadata recorded after Start flow.
  • Request payload shape with text and identifiers redacted.
  • DOM structure with visible text, form values, scripts, and sensitive attributes removed.
  • A styling-target inventory with data-attribute names and constrained UI enum values.
  • Optional response schemas for conversation list and message reads. Response text itself is not persisted.
  • A request summary grouped by host, method, and path.
